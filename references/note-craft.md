# 课堂笔记内容规范（模型侧细则）

> 来源：JLearning `lecture-notes` 心法 + 教学实践补充。
> 本文件是 `lecture_notes.py` 里 prompt 约束的详细说明。改 prompt 时同步改这里。

## 核心心法

> **对于公共知识，获取说话人的意图比获取他表达的信息更重要**——因为后者 AI 比人更擅长。

笔记要还原的是「老师为什么这样讲」，而不是「老师说了哪些词」。

## 一、噪声过滤

**必须去除**

- 口头禅：嗯、啊、这个、那个、就是说、你知道、对吧
- 重复讲解（第一次保留，后续删除）
- 跑题闲聊、与知识无关的课堂管理话术（"好，我们休息一下""等一下有人还没进来"）
- 技术故障说明（"刚才那个声音不清楚""PPT 翻页出问题了"）

**必须保留**

- 学生提问中揭示关键概念的部分
- 老师对易错点的强调（"这里最容易错""记住这个"）
- 老师明确说"这是重点""这会考"
- 老师用来帮助理解的**关键比喻、口诀、类比**（用引号标注，这是口语讲授最有价值的部分）

## 二、逻辑重构

- 老师讲得跳跃或混乱时，按**学科内在逻辑**重排，不拘泥于原始顺序。
- 例子必须与对应理论点**紧邻**放在一起，不要集中堆到章节末尾。
- 推导步骤缺失时：先尝试从上下文推断；推断不出则标 `[此处推导步骤缺失，建议核对原文]`。
- 原顺序与逻辑顺序冲突时以逻辑顺序为准，可用注释保留"原录音提到于 MM:SS"。

## 三、术语纠错

转录（尤其 Vosk 小模型 / 自动字幕）常见错误与纠正方式：

| 错误类型 | 示例 | 纠正 |
|---------|------|------|
| 希腊字母 | "alpha"→"阿尔法" | 按学科判断 α / β / γ / θ / Δ / Ω |
| 数学符号 | "subset"→"sub class" | 按上下文判断 ⊂ / ⊆ / ∈ |
| 专有名词 | "Python"→"派森" | 保留英文原形 |
| 化学式 | "H2O"→"H二O" | 纠正为标准化学式，下标用 LaTeX |
| 运算符 | "times"→"乘以" | 数学上下文转 × / · |
| 比较符 | "greater than"→"大于" | 按上下文转 > / < |
| 中文同音 | "精灵痔疮"→"京灵智创" | 结合主题与上下文 |

**不确定时：标 `[原词? → 推测词]`，绝不静默替换。**

## 四、内容补全（严格约束）

**仅在以下三种情况才允许补全：**

- a) 老师明确提到某术语 / 公式 / 定理，但没给定义或完整形式
- b) PPT 上显然有信息但没念出来，导致上下文断裂
- c) 某推导步骤明显缺失，导致逻辑不通

**硬性要求：**

- 所有补全内容必须进 `supplements`，网页上渲染为紫色「AI 补充（老师未讲，仅供衔接）」块
- 每条补全必须写 `reason`，说明为什么必须补
- 不确定时宁可标 `[此处录音不清，建议核对原文]`

**禁止：**

- "锦上添花"式扩展
- 老师没讲的内容
- 超出课堂范围的深入讲解
- 为显示 AI 能力而添加的额外知识点

## 五、公式与图表

| 内容类型 | 处理方式 |
|---------|---------|
| 数学 / 物理 / 化学公式 | LaTeX。行内 `$...$`，行间 `$$...$$` |
| 结构关系 / 流程 / 分类 | Mermaid（`diagram_mermaid` 字段） |
| 对比 / 参数汇总 | Markdown 表格或 `terms` 列表 |
| 复杂示意图 | 文字描述 + `[配图建议：XXX]` |

**只在对理解有实质帮助时生成图表，不要为了好看而加图。**

## 六、分学科处理

| 学科 | 侧重 |
|-----|------|
| 理工科（数/理/化/计/AI） | 推导每一步都呈现；保留定义的精确数学表述；概念关系图优先 |
| 工程类（建筑/制造） | 技术规格表格、流程图、层次结构图；强调应用场景与设计约束 |
| 人文社科（文/史/哲/金融/心理） | 理论脉络清晰；学派/观点对比用表格；保留关键引用原文 |
| 语言类 | 例句、语法规则表、易混点对比 |

## 七、长文本切分

- 脚本按时长机械切段；模型在段内按**自然话题切换点**组织内容
  （"好，我们接下来讲…""现在换个话题""关于 X…"）
- 段数由 `--max-segments` 与 `--min-segment-seconds` 控制，默认每段 ≥ 60 秒、最多 14 段

## 八、语言风格

- 简洁、准确、无废话；书面语
- 保留老师的关键比喻与口诀
- **禁止**："让我们""接下来""综上所述""大家注意""好，那么"等演讲腔
- **禁止**：冗长过渡句，直接切入主题
- 输出语言默认与授课语言一致

## 九、质量检查清单（交付前逐项核对）

- [ ] 基本信息完整，无编造（用 `[未提供]` 而非编造）
- [ ] 知识框架能一眼看出整堂课脉络
- [ ] 每节按「定义 → 原理 → 例子 → 要点」展开
- [ ] 公式已用 LaTeX
- [ ] 需要图表处已给 Mermaid
- [ ] 重点与考点已单独汇总，且来自老师强调
- [ ] 补全内容全部在 `supplements` 里
- [ ] 术语纠错已标注
- [ ] 无演讲腔填充词
- [ ] 无超出讲授范围的扩展
- [ ] 无遗漏重要知识点
